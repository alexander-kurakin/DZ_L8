# Factory feel — целевое ощущение боя

**Status:** черновик направления · **v2 (build-only damage)** — см. §12  
**Связь:** [[00-one-pager]] · [[pillars]] · [[balance]] · [[balance-budgets]] · **[[plan-v3]]**  
**Референс по ощущению:** King is Watching (не клон механик)

---

## 1. Целевое ощущение (один абзац)

Между волнами я **настраиваю 2–4 спицы** под известный план угроз. В бою **смотрю**: яд тикает, турели стучат, толпа медленно плывёт, враги **сочно лопаются**. Иногда — LMB или перестановка, не сопровождение каждой пачки. Башня теряет **запас прочности дискретно** (удары / charges), а не тает с 2000 до 0 за десять секунд, если я один раз ошибся с раскладкой. Пик — **доверие к пути**: «эту спицу я заставил, она переварит свой поток».

---

## 2. Фабрика ≠ оценка каждой угрозы

| Старая ментальная модель (куда уехали итерации) | Целевая модель |
| ----------------------------------------------- | -------------- |
| Каждый враг — мини-босс, нужен добив | Поток — конвейер, растения **перемалывают** |
| Успех = успел LMB + брат по всем секторам | Успех = **путь настроен**, редкий ремонт |
| Сложность = больше одновременных пожаров | Сложность = **глубже слои** O→M→I, не шире хаос |
| Чилл = идеальный клик в сектор | Чилл = **наблюдение** тиков и анимаций |

**Доверие к пути:** на препе я знаю, *что* придёт на спицу N; заставил O/M/I под этот поток → в бою не пересматриваю каждый экземпляр.

## 3. Референс: King is Watching — что важно

Не копировать сетку королевства, а **контракт с игроком**:

| Элемент референса | Зачем игроку |
| ----------------- | ------------ |
| Очень долгий подход к стене | Время для DoT, турели, чтения поля |
| **100 ударов**, не 100 HP | Ошибка = −1 из запаса, не burst melt |
| Таймлайн волны, равные интервалы | Ритм: сделал → подождал → сделал |
| Ускорение / пауза боя | Контроль темпа **наблюдения** |
| Партиклы, мелкие анимации | Сочность **без** спешки |
| Много систем, медленный бой | Решения на препе, бой — шоу |

Уже есть в [[pillars#2. Less clicks (Меньше кликов!)]]: Toy Defense, King is Watching — смотришь, иногда вмешиваешься.

## 4. Чем Spellcore **не** King is Watching

| Наше | Сохраняем |
| ---- | --------- |
| Радиальная Spellcore-сетка (4 пояса × пути) | Да |
| Essence, vacuum, кормление башни | Да |
| Брат + принцесса, family pillar | Да |
| Секреты S1–S9, разблокировка растений | Да |
| Три архетипа: кот / танк / дракон | Да (роли могут смягчиться) |

Меняется **темп, leak-модель, предсказуемость путей, доля ручного добива**, не обязательно весь проект.

## 5. Четыре опоры (дизайн-рычаги)

### 5.1 Время подхода

- Низкая скорость мобов и/или **длинная** дистанция Spawn → Inner.
- Паузы между **пакетами**, не только между мобами внутри паровоза.
- Цель: растения успевают **отработать на глазах**; игрок не в режиме «горящей жопы».

### 5.2 Дискретный leak (удары / integrity)

- Башня держит **N ударов** (или charges), не плавный HP-пул 2000.
- Танк с Middle, дракон с Inner, кот-взрыв — разный «вес» удара, но **с потолком** на волну.
- Цель: комбо tank+dragon ≠ снос 2000→0 за ~10 с без контрмер.

### 5.3 Публичный таймлайн + контроль скорости

- До боя видно: **кто, когда, с какой спицы** (не shuffle в голове).
- Между метками — окно на микро-решения (доставить mine, LMB по котам).
- Опционально: ×1 / ×2 / пауза в бою (как в референсе).
- Цель: ритм фабрики, не каша одновременных спавнов.

### 5.4 Контракт пути

- Число **активных** спиц на волну ≈ число угроз (или явно помечены «тихие» пути).
- Нет random shuffle групп по путям без игрока ([[factory-feel#7. Текущий разрыв с кодом]]).
- Заставленная спица **закрывает свой типовой поток** без обязательного брата/LMB на каждого танка.
- Цель: **доверие**, не гадание.

## 6. Анти-паттерны (чеклист playtest)

Если на W3–W5 отмечаешь **да** — это не factory feel, даже если победил:

| ID | Анти-паттерн | Симптом |
| -- | ------------ | ------- |
| **a** | Гадание порядка | Неясно, на какую спицу приедет следующая серьёзная угроза |
| **b** | Мёртвые пути | Открытая спица без стрелки / без угрозы — Essence вложен впустую |
| **c** | LMB-баф постройки | Каждая пачка требует ручного **урона** LMB по секторам (в v2 — только баф, см. §12) |
| **d** | Burst melt | 2000→0 (или аналог) за один заход волны, почти без рычагов |
| **e** | Очередь на брата | Несколько танков — добив только братом (в v2 брат не DPS — §12) |
| **f** | Параллельный ад | 3–4 активные угрозы на разных спицах, недобитки копятся быстрее добива |

**Шкала сессии (30 с боя W3):** 1 = хочу смотреть · 5 = горящая жопа. Цель демо: **≤ 2.5** на W4, **≤ 3** на W5 при первом прохождении.

## 7. Текущий разрыв с кодом

| One-pager / pillars | Реализация сейчас | Влияние на feel |
| ------------------- | ----------------- | --------------- |
| Few plants, watch combat | Много слотов, добив братом/LMB | Less clicks нарушен |
| Factory peak | Параллельные группы, overlap | Какофония |
| Preview на путях | `WaveSpawnPlanService` **shuffle** путей каждую волну | Анти **a**, **b** |
| LMB слабый, на CD | LMB 20% по танку + коты 50% | Всё ещё escort на пачках (**c**) |
| Слои O→M→I | Танк: 2×mine + добив ≠ автономный путь | Нет **доверия** |
| — | Tower `MaxHealth` 2000, variable DPS leak | Анти **d** |

Shuffle (для справки): группы round-robin по **перемешанному** списку путей — превью показывает иконки, но привязка «я минирую спицу 2 под танка» ненадёжна.

## 8. Что оставить / что сдвигать

### Оставить (пока)

- Сетка, пояса, Path unlock, Essence economy.
- Три типа врагов (роли пересмотреть, не удалять).
- Брат как персонаж / эмоции (не обязательно главный DPS).
- 5 волн meetup scope.

### Сдвиг (направление, не коммит в цифры)

| Область | Направление |
| ------- | ----------- |
| Темп | ↓ скорость мобов; ↑ паузы между пакетами |
| Урон | Sustained tick (toxic, turret, mine-зона) > instant proc + добив |
| Танк | Толстый вагон в потоке; путь дожимает за N сек, брат — страховка |
| Волна W5 | Сериальные пакеты, не 8 наложенных групп |
| Башня | Integrity / удары (или жёсткий leak cap) вместо голого HP |
| Спавн | Фикс-план или таймлайн вместо random shuffle |
| Juice | Тики яда, выстрелы турели, попы — приоритет «смотреть приятно» |

**Итерации mine 150/200, dragon HP, паузы Intro5** — тюнинг внутри **старой** модели; не закрывают a–g.

## 9. Минимальный тех-список (прототип-ось)

Порядок — от дешёвого к дорогому; каждый шаг — отдельный playtest по шкале §6.

1. **Shuffle off** — детерминированная раскладка групп на пути (или фикс в `Intro*.asset` per path).
2. **Группы = пакеты** — не спавнить группу N+1, пока на поле > K врагов (или таймаут «тишины»).
3. **↓ MoveSpeed** глобально (−30–40%) + ↑ `PauseAfterGroup` на W4–W5.
4. **Tower integrity prototype** — 50–100 «ударов», веса по типу врага (отдельный конфиг).
5. **Timeline UI stub** — полоска преп + боя: метки спиц / типов (даже без speed control).
6. **Speed control** — `Time.timeScale` 1 / 2 / 0 в бою.
7. **Mine как зона/tick** — второй режим рядом с proc (A/B в одной волне).

Полный редизайн не обязателен до прохождения **п.1 + п.3 + playtest W3** на шкале ≤ 2.

## 10. Вертикальный срез (предложение)

Одна волна (**Intro3** или упрощённый `Intro3_factory_test`):

- 3 пути, **фикс** привязка групп.
- 3 группы макс. «в пути», пауза 1.5 с.
- MoveSpeed ×0.6.
- Танк: O toxic + M mine **дожимают без брата** за ~12 с на пути.
- Башня: 30 integrity, танк −2, кот −1, дракон tick −1/сек cap.

Критерий успеха среза: тестер описывает бой словами **«смотрел / подкрутил»**, не **«тушил»**.

## 12. Направление v2 — урон **только** от построек

Черновик от playtest-обсуждения. Заменяет модель «брат + LMB добивают» на **три способа убийства толп** + пассивная семья.

### 12.1 Ядро

| Было | Стало |
| ---- | ----- |
| Урон: mine, toxic, turret, LMB, брат | Урон врагам: **только постройки** |
| LMB = урон по сектору | LMB = **баф постройки** (принцесса) |
| Брат = камни Middle/Inner | Брат = **медленный ремонт** башни |
| Башня 2000 HP | Башня **~200 ударов** (integrity) |

**Фантазия:** садистское **наблюдение** — три разных «как умирают толпы» (взрыв мины, прострел турели, яд в луже). Игрок — режиссёр фабрики, не снайпер.

### 12.2 Лестница волн (teach)

| Wave | Открытие | Урок | Ожидание на пути |
| ---- | -------- | ---- | ---------------- |
| **W1** | LMB (позже баф), Mine | Одной **мины** на пути хватает на **всех котов** волны | 1× Mine на спице |
| **W2** | Tank | **Щит** танка: первая мина не дожимает → нужна **вторая** мина на том же пути | 2× Mine на Middle (или 2 proc на танка) |
| **W3** | Turret, Dragon | Дракон **пролетает** mine/toxic/LMB — убивает только **турель** (гарантированно) | Inner turret на спице с драконом |
| **W4** | Toxic | Лужа на **Outer**: сильный slow на всех **кроме** драконов; дожим потока до mine/turret | Toxic O на дальнем кольце |
| **W5** | Всё вместе | Фабрика на нескольких спицах; LMB-баф на плотные пакеты | Слои O→M→I по контракту пути |

W1 free mine / plant bar — без изменения идеи teach из [[00-one-pager#3. Tutorial unlockable flow]].

### 12.3 Матрица контров (целевая)

| Угроза | Mine | Toxic (O/M) | Turret | Пролет / иммунитет |
| ------ | ---- | ------------- | ------ | ------------------ |
| **Cat** | ✅ основной | ✅ slow + DoT | ✅ | — |
| **Tank** | ✅, **щит** режет 1-й удар сильно | ✅ slow (не убивает сам) | частично / вторично | стоит на Middle |
| **Dragon** | ❌ пролет | ❌ пролет | ✅ **единственный гарант** | воздух |

Щит танка — не «LMB не пробивает», а **mine needs 2**: первая снимает щит / часть HP, вторая добивает (или вторая мина на том же Middle).

### 12.4 Турель — ослабить хардкор прострела

Сейчас: дуга N±1 на том же поясе — узко, легко промахнуться по смыслу «фабрики».

**Целевое:**

- Стреляет по **всему пути** (все пояса на спице), не только соседние сектора.
- **Приоритет:** летающие (дракон) > остальное.
- Если летающих нет: по наземным с **50% урона** (или наоборот: full по ground, priority snap на dragon).
- Цель: одна турель на Inner **закрывает** дракона на этой спице без микроменеджмента.

### 12.5 Toxic (W4+)

- Сильное **замедление** всего, что идёт по земле.
- **Драконы не замедляются** (пролетают / immune slow).
- Предпочтительная позиция: **Outer** — максимум времени в луже, коты и танки «плывут» в зону mine/turret.
- Урон toxic — тиками, визуально читаемо (сочность наблюдения).

### 12.6 Брат — ремонт, не DPS

- Автоматически **чинит integrity** башни, **медленно**.
- Часто **отвлекается** на idle-анимации (family pillar, юмор) — ремонт прерывается.
- Не бросает камни во врагов в этой модели.
- Игрок не ждёт брата как киллера; ждёт **постройки**. Брат — тёплый фон + слабая страховка от leak.

### 12.7 Башня — integrity (~200 ударов)

- UI: «200 ударов» / charges, не HP 2000.
- Кот / танк / дракон — разный **вес удара** по башне при leak (числа в [[balance]] после прототипа).
- Ошибка = −N из запаса, не melt за 10 с (см. §5.2).

### 12.8 LMB → баф постройки (принцесса)

- **Тот же визуал** (морозный выстрел / орбы) — но эффект: накладывает на **постройку** в секторе, не урон врагам.
- **+50% урона** постройки на **60 с**.
- **Макс. 2** одновременно бафнутых постройки на всё поле.
- Не нужно часто переставлять — но на **плотной группе** / важной спице баф решает исход.
- Закрывает анти-паттерн **c** (§6): не escort огнём, а **усилить узкое место фабрики**.

### 12.9 Анти-паттерны v2 — переоценка

| ID | В v2 |
| -- | ---- |
| **c** | LMB не сопровождает пачки уроном — баф 2 слотов |
| **e** | Нет очереди на брата-киллера |
| **d** | Integrity 200 вместо HP melt |

Остаются: **a** shuffle, **b** мёртвые пути, **f** параллельный спавн — лечатся таймлайном и §5, не только v2.

### 12.10 Что выкинуть / отключить в коде (когда пойдём в прототип)

- `TowerBrotherStoneThrowSystem` как источник урона (или только juice без damage).
- `ExplodeAtPointSystem` — прямой урон котам/танкам → редирект на `BuildingBuffSystem`.
- `PlantDamageCounterService` — пересмотр множителей под щит танка и «dragon flies over».
- Таргетинг турели — новая логика path-wide + air priority.
- `LevelConfig.TowerMaxHealth` → `TowerIntegrityMaxHits` (или аналог).
