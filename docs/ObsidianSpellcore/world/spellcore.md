
Spellcore = Магическая паутинка на полу поля боя - не декор, а **язык правил**: куда смотреть, куда ставить, откуда идут угрозы.

## Образ
- Сетка c секторами, ближайшее сравнение с реальностью - поле дартс
- Дырки-слоты - места для активных способностей в заданных позициях
- 16 четких секторов

## Роль для игрока
- Читать поле - без туториала - откуда идут враги, что можно с этим сделать
- Чувство роста: паутинка **раскрывается** по мере мастерства ([[pillars#3]])
